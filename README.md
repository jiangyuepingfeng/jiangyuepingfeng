# 人学——你为何心痛？——身心自救指南

**作者：江月凭风** ｜ 2026 丙午年秋分 ｜ GitHub 开源出版

> 这本书写的是人本身。你心里那个反复解不开的结、那种内耗，在这本书里只是一个入口——因为它最能暴露人是怎么被驱动、又怎么把自己找回来的。

本书不是医学著作，不是心理学教材，也不是宗教灵修。它是一套理解框架——是指月亮的那根手指，月亮要你自己去看。

## 这本书从外到内，讲的是什么

- **外层 · 入口**：心理问题（反复的内耗、低落、循环痛苦）只是标本，不是主题。它是最常见、最完整的病例，借它看清人的底层结构。
- **中层 · 地基**：气 / 能量 / 身心三系统。心理问题不是单纯的"想不开"——它会以能量的形式留在身体里，牵动意识、大脑、藏腑，是一个互相影响的系统。
- **内层 · 主旨**：大脑在不停地推送旧模式，但签收权在你。看清之后，把被夺走的主体性收回来——今日方知我是我。
- **核心 · 寓意**：不只是"我好了"，而是让伤害在自己这里断掉，不再传给下一个空白的人。

## 读之前，先分清这是两层

这本书同时在说两件事，别读混：

- **客观层**：它摆给你看"棋盘残局"——身心、气、男女差异、年纪越大回路越固化，这些规律本来长什么样。这是在描述事实。
- **主观层**：它不替你做决定。看清残局之后怎么活——定义权收回、爱自己、不接招——是你自己的事。

一句话：书里摆的是你拿到的牌长什么样，**不是你只能这样打**。地图是手指，不是月亮。

## 三卷

- **上卷 · 人是什么**：气与能量、神气形质、藏腑经脉、意识与身心三系统。前半部分概念较密。
- **中卷 · 为什么会痛**：一个心理问题从被植入、存进身体、被触发，到反复循环的完整机制。
- **下卷 · 可以怎么走**：应对方法，像一个工具箱——读到想动手解决时再翻。

**建议读法：先读中卷，再读上卷。**

> 术语说明：入口处我们用"心理问题"，是因为不是所有人都愿意说自己"有创伤"；书里会用更准确的词——心理创伤——来指同一个东西。你那个反复想不开的结，就是它。

## 这是给谁的

一句话：给向内求的人。只认双盲实验、拒绝身心关联、想要速成捷径的人，这里对你没用。

## 阅读提示

- **文化门槛**：书里大量用气、阴阳、藏腑、经络这些传统概念，上卷前半会比较吃力。
- **阅读安全**：涉及情绪与创伤，若读时持续情绪剧烈波动、失眠，或出现自伤冲动，请停下，找专业帮助。
